# Security policy

Fita stores master data that often includes personal data, and it runs with read access to core company systems. We take reports seriously.

## Reporting a vulnerability

Please use GitHub private vulnerability reporting on this repository ("Security" tab, "Report a vulnerability"). Do not open a public issue.

Include the version, a description, steps to reproduce and the impact you expect. We acknowledge reports within 3 working days and aim to ship a fix for confirmed issues within 30 days, sooner for critical ones.

## Supported versions

Before v1.0 only the latest release receives security fixes. From v1.0 on, the latest release and the one before it.
