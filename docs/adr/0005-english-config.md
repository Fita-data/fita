# 0005. Configuration keys, commands and API in English

Status: accepted

## Context
Fita targets an international community, but users name their own domains and attributes.

## Decision
Config keys, CLI commands, API routes and code are in English. Names chosen by users (domains, attributes, rules) can be in any language. The UI is fully translatable.

## Consequences
One vocabulary for docs and code. Examples in the docs may show non English attribute names on purpose.
