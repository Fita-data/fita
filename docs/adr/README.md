# Architecture decision records

One file per decision, numbered, never rewritten. If a decision changes, write a new ADR that supersedes the old one and update the old one's status line.

Template:

```
# NNNN. Title

Status: proposed | accepted | superseded by NNNN
Date: YYYY-MM-DD

## Context
What forces us to decide.

## Decision
What we do.

## Consequences
What gets easier, what gets harder.
```
